# Автозапуск хуков

Реестр: какой хук при каком событии агент запускает сам. Правила — `AGENTS.md`, п. 8.2.

- Одна строка — одна привязка «событие → хук». Один хук может быть привязан к нескольким событиям, к одному событию — несколько хуков.
- Хуки одного события запускаются в порядке строк.
- Событие — только из списка в `AGENTS.md`, п. 8.2: `task-start`, `worktree-created`, `before-commit`, `after-commit`, `before-push`, `stand-up`, `before-stand-down`, `task-done`.
- Аргументы могут содержать подстановки: `{ws}`, `{task}`, `{branch}`, `{worktree}`, `{stand}`. Если аргументов нет — `—`.
- Чтобы временно выключить привязку, удали строку или перенеси её в раздел «Выключено».
