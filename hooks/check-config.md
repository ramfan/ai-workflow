# Хук: check-config

**Назначение:** проверить все YAML-настройки по схемам из `rules/config.md` и показать ошибки. Ничего не меняет.

## Аргументы

| Аргумент | Обязательный | Что это |
|---|---|---|
| `<ws>` | нет | Имя пространства. Без него проверяются все пространства. |

## Что нужно до запуска

- Прочитан `rules/config.md`.

## Шаги

Хук только читает файлы. Значения секретов не выводит — только имена ключей.

0. Запусти `$ROOT/bin/check-config [<ws>]` и покажи его вывод. Если скрипт не запускается (нет Python 3 или PyYAML) — выполни шаги 1–4 вручную.
1. **`env.yaml`.** Прочитай `$ROOT/env.yaml`. Нет файла — ошибка «создай по `templates/env.yaml`», дальше не проверяй. Сверь со схемой (раздел 2): обязательные поля, типы, лишние поля, неизвестные подстановки `${...}`. Проверь, что `tmp_dir` существует или может быть создана, `proxy.dir` (если не `null`) содержит `bin/envctl`.
2. **`$SECRETS`.** Файл существует, читается как YAML, плоский словарь, ключи по шаблону `[A-Z][A-Z0-9_]*`, значения — строки. Пустые значения отметь как «не заполнено».
3. **Пространства.** Для каждой папки в `workspaces/` (или только `<ws>`):
   - есть `ws.yaml`; нет — «папка без `ws.yaml`, не пространство»;
   - сверь со схемой (раздел 3): `name` равен имени папки, каждый `sources[].path` существует, для `kind: repo` внутри есть `.git`, каждый файл из `rules` существует, каждый ключ из `secrets` есть в `$SECRETS`, при `stands.proxy: true` в `env.yaml` задан `proxy.dir`;
   - в корне пространства нет папок, кроме `rules/`, `tasks/`, `_archive/`.
4. **Задачи.** Для каждой папки в `workspaces/<ws>/tasks/` и `_archive/`:
   - есть `task.yaml`; нет — «папка без `task.yaml`, не задача»;
   - сверь со схемой (раздел 4): файл `issue` существует, `stage: implement` требует `git.branch` не `null`, значения `commit` / `push` из `true | ask | false`.

## Результат

Таблица по каждому проверенному файлу: путь, «ок» или список ошибок (поле — что не так). В конце — общий итог: сколько файлов проверено, сколько с ошибками. Если ошибок нет, так и скажи.
