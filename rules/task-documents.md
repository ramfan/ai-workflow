# Расширение: документы задачи

Это расширение правил из `AGENTS.md` (раздел 6). Оно обязательно так же, как основной документ.

---

## 1. Вопросы и план

- Все вопросы по задаче агент пишет только в `$TASK/questions.md`. Это вопросы к человеку, неясности, решения, которые нужно принять.
- В `$TASK/plan.md` — только план: исправления, реализации или исследования. Вопросов в нём нет.
- Если план зависит от ответа на вопрос, в `plan.md` ставится ссылка на вопрос в `questions.md` (например, «см. `questions.md`, вопрос 3»). Сам вопрос в `plan.md` не повторяется.
- Вопросы в `questions.md` нумеруются. Когда человек ответил, ответ записывается под вопросом, вопрос не удаляется.
- Текст обоих файлов — по `rules/human-readable-texts.md`.

### 1.1. Структура `questions.md`

Файл называется только `questions.md` (не `question.md`, не `вопросы.md` и т. п.). Структура у всех задач одинаковая.

```markdown
# Вопросы по <задача> (<кратко, о чём задача или пространство>)

## 1. <Короткий заголовок вопроса>

<Контекст: что известно, откуда (файлы, разделы, ссылки на другие задачи), какие есть варианты.>

<Сам вопрос — одним предложением с вопросительным знаком.>

Ответ: <ответ человека или пусто, пока ответа нет>

## 2. <Следующий вопрос>

...
```

- Заголовок файла — один, уровня `#`: `Вопросы по <задача>` и в скобках уточнение.
- Каждый вопрос — раздел уровня `##` с номером и коротким заголовком: `## <N>. <Заголовок>`. Номера идут подряд с 1, не переиспользуются и не меняются.
- Внутри вопроса в таком порядке: абзац контекста, отдельный абзац с самим вопросом, строка `Ответ:`.
- Строка с ответом есть у каждого вопроса, без исключений. Новый вопрос, на который ещё не ответили, агент записывает сразу со строкой `Ответ: ` (двоеточие и пробел, дальше пусто). Человек дописывает ответ в эту строку.
- Уточнения, полученные позже (например, в чате), дописываются после строки `Ответ:` отдельным абзацем: `Уточнение в чате (<ГГГГ-ММ-ДД>): <текст>.`
- Новые вопросы добавляются в конец файла.

---

## 2. Краткая памятка

| Действие | Разрешено? |
|---|---|
| Вопросы по задаче в `questions.md` | Да |
| Вопросы в `plan.md` | Нет, только ссылка на вопрос в `questions.md` |
| В `plan.md` что-либо, кроме плана | Нет |
| Удалить вопрос из `questions.md` после ответа | Нет, ответ записывается под вопросом |
| Файл вопросов с другим именем (`question.md` и т. п.) | Нет, только `questions.md` |
| `questions.md` в своей структуре | Нет, только по разделу 1.1 |
| Перенумеровать вопросы | Нет |
| Вопрос без строки `Ответ: ` | Нет, у нового вопроса строка `Ответ: ` пустая |
